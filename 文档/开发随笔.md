# 函数回调
2025.11.10目前看来算是明白所谓的函数回调了
目前他的思考模型(R1)是不支持函数回调的，仅仅V3支持，估计是R1它没法明白规整化输出
其中有一个参数是返回格式，有文本和json
json的意义我想就是你自己写函数回调
## 回调逻辑
本质就是2次调用
```flowchart TD
A[用户提问<br>杭州天气?] --> B(第一次模型调用)

subgraph B [模型分析阶段]
    B1[模型分析用户意图]
    B2[识别需要调用<br>get_weather函数]
end

B --> C{模型返回函数调用指令}

C --> D[程序模拟调用函数<br>返回: 24℃]
D --> E(第二次模型调用)

subgraph E [模型整合阶段]
    E1[结合函数结果与<br>原始问题]
    E2[生成最终的自然<br>语言回答]
end

E --> F[最终回答<br>杭州天气24℃]
```
